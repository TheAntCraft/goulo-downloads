# Goulo Client – Downloads

Fertige Versionen des Goulo Launchers. Kein Quellcode.
Inoffiziell, nicht von Mojang oder Microsoft. Zum Spielen wird ein gekauftes Minecraft: Java Edition benötigt.

**[→ Neueste Version](https://github.com/TheAntCraft/goulo-downloads/releases/latest)**

| System | Datei |
|---|---|
| Linux | `Goulo-Linux-Installer.sh` – eine Datei, lädt und installiert alles |
| Windows | `Goulo-Windows.zip` – entpacken, `Goulo.exe` starten |

### Linux installieren
```sh
bash Goulo-Linux-Installer.sh
```
(oder: Rechtsklick → Eigenschaften → „Als Programm ausführen“ erlauben, dann doppelklicken)

Der Launcher aktualisiert sich bei jedem Start selbst.
